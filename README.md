# Assessment 2 – Foundation of Data Science

## Overview

This repository contains our **Assessment 2 for Foundation of Data Science**.

This was a **team-based assessment** where each team member independently developed an analysis question based on the available dataset and investigated the question using appropriate **statistical methods**.

The main goal of the assessment was to apply concepts from data science and statistics to a practical dataset, including:

* Formulating an analysis question
* Exploring and preparing the data
* Selecting an appropriate statistical method
* Performing the analysis
* Interpreting the results
* Drawing conclusions based on the statistical findings

## Team Analysis

Each team member worked on a separate analysis question. The individual analyses are organised into separate folders within this repository.

## Approach

Although each team member investigated a different question, the overall process followed a similar data analysis workflow:

1. **Question Formulation** – Develop a question that can be investigated using the dataset.
2. **Data Preparation** – Inspect and prepare the relevant data for analysis.
3. **Exploratory Analysis** – Explore patterns, distributions, and relationships within the data.
4. **Statistical Testing** – Select and apply an appropriate statistical method to investigate the question.
5. **Results** – Examine the statistical results and supporting visualisations.
6. **Interpretation** – Explain what the results suggest in relation to the original question.
7. **Conclusion** – Summarise the findings and acknowledge any relevant limitations.

## Purpose

This assessment demonstrates our ability to apply fundamental **data science and statistical concepts** to real-world data and communicate the results of an analysis in a clear and structured way.

Each individual analysis can be explored in its respective folder.
